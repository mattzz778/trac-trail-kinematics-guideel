# trac-trail-kinematics-guide
Tractor-Trailer Kinematic Simulation & ROS2 BridgeThis repository provides a complete pipeline for processing GPS trip data, simulating trailer kinematics, and exporting synchronized vehicle states into a ROS2 bag. This is specifically optimized for high-fidelity simulation environments like CARLA.🚀 FeaturesKinematic Simulation: Accurate trailer trajectory generation based on tractor GPS inputs.High-Fidelity Interpolation: Upsampling to 100Hz using Spline interpolation for smooth physics engine performance.Signal Conditioning: Automated phase unwrapping (heading angles) and jitter removal via Savitzky-Golay filtering.CARLA Compatibility: Automatic coordinate inversion for Left-Handed simulation environments.Visual Validation: Comprehensive plotting suite including satellite-view geographic alignment.🛠 PrerequisitesMATLAB (R2021a or later recommended)Simulink (with tractor_trailer_kinematics.slx model)ROS Toolbox (required for ros2bagwriter)Automated Driving Toolbox (recommended for geographic plotting)📖 Usage GuideFollow these steps in order to process a trip and generate a ROS2 bag:1. InitializationRun initialize.m to load the dataset and configure vehicle parameters.Data Source: It looks for saved-gps_trips_data_snapped.mat.Trip Selection: You will be prompted to enter a Trip ID from the dataset.Configuration: The script automatically calculates kinematic offsets ($d$) and prepares timeseries objects for the simulation.2. Simulation & AnalysisRun runplot.m to execute the kinematic model and generate visualizations.Model Execution: Runs the tractor_trailer_kinematics Simulink model.Kinematic Processing: Calculates articulation angles and simulates the trailer's "swing" and "pull" velocity components.Data Export: Saves processed results to Full_Vehicle_Data_Trip_X.csv and .mat files.Visuals: Displays 5 validation plots, including speed profiles, angular dynamics, and local/geographic paths.3. ROS2 Bag ExportRun ros_last_25.m to convert the processed data into a ROS2 bag file.Upsampling: Data is interpolated from original frequency to 100Hz ($dt = 0.01$).Filtering: Applies a smoothing window to remove GPS sensor noise and jitter.Bag Writing: Writes to a custom topic /tractor_01/saved_vehicle_control using the message type saved_msgs/TractorTrailerState.Output: A uniquely named folder containing the ROS2 bag will be created in your current directory.📂 File Structureinitialize.m: Dataset loading and vehicle dimension setup.runplot.m: Simulation control, kinematic calculations, and plotting.ros_last_25.m: ROS2 bag generation, filtering, and interpolation.tractor_trailer_kinematics.slx: Simulink model for trailer kinematics.📊 Key OutputsFull_Vehicle_Data_Trip_X.csv: Combined tractor and trailer state data.ROS2 Bag Folder: Ready-to-play data for CARLA or ROS2 nodes.Validation Figures: Graphical proof of kinematic alignment and signal integrity.
